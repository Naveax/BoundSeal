# nxb-post-closure-governance

Deterministic local-only contracts for NXB-102 through NXB-119.

- P16 governs successor lineage, compatibility envelopes, metadata-only state transfer, canonical cutover and succession certification.
- P17 governs independent review panels, deterministic evidence sampling, assignment coverage, finding remediation and renewal certification.
- P18 governs public-verification bundles, bounded trust epochs, diverse verification quorum, capability-free sunset and exact program closure.

The crate is anchored to `LifecycleClosureCertificate` from NXB-101. It exposes no socket, resolver, browser, scanner, transport, process, shell, deployment, credential-discovery or destructive-testing API.
